# Week 03 engineering log

This week I built a reproducible network impairment lab and extended the robot link with liveness monitoring, recovery, and bounded telemetry replay. The lab routes one robot through Toxiproxy while a second robot uses a direct connection as a control. Linux netem supplies the packet-loss scenarios. Each measurement script records the configuration and measured output so the same experiment can be repeated during the later performance phase.

The experiment design carries forward the useful structure of a latency-injection testbed. Separate the workload from the network profile, keep the scenario and random seed explicit, and collect observations with scripts. A clean baseline is necessary before interpreting a delayed or interrupted run. I also kept an unaffected robot active during every profile, which makes fleet-wide side effects observable.

Reconnection introduced a different problem from simply delaying a running connection. After an outage, the robot can have telemetry that the gateway never received, telemetry whose acknowledgement was lost, and newer samples still being generated. Reusing one counter for every purpose would mix connection ordering with recovery state. I retained the per-connection envelope sequence and added a persistent telemetry sample sequence. A resumed session returns the server's accepted sample cursor. The robot then sends its remaining buffer in order, subject to a rate limit. Duplicate samples leave the latest pose unchanged.

The bounded buffer makes the retention tradeoff explicit. At five samples per second, 300 entries retain roughly sixty seconds. Overflow removes the oldest sample and records the drop. The gateway records gaps so a later analysis can distinguish missing samples from transport retransmissions. TCP can hide packet loss by retransmitting, which is why the application sequence-gap metric cannot measure the underlying packet-loss percentage.

I also changed fleet task ownership. A fatal error in one robot is collected while the other robots continue their scenarios. Recoverable disconnects retry independently with bounded exponential backoff and full jitter. The local deadman stops movement when gateway responses stop arriving. The next phase will apply the documented clock uncertainty and expiry policy to motion commands and add the complete command lifecycle. The present report records measured results and keeps future safety guarantees separate from checks exercised in this week's tests.
